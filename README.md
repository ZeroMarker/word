# IELTS 单词卡片

一个无需构建步骤的 IELTS 单词学习网页。支持卡片翻面、单词/单元切换、系统英语发音、键盘操作，并自动保存上次学习位置。

## 本地运行

浏览器出于安全限制不能直接通过 `file://` 读取词库，请在项目目录启动一个静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 操作方式

- 点击卡片或按空格：翻面
- 左右滑动或方向键左右：切换单词
- 上下滑动或方向键上下：切换单元
- 点击音标、顶部扬声器或按 `P`：播放发音

词汇数据来自 `word-list.txt`。若词库加载失败，页面可切换到内置示例数据。

## 其他学习方式

项目同时提供独立的[每日一词](daily-word/index.html)：每天自动按「名词 → 动词 → 形容词」轮换推送一个核心词，并以发散图展开**同词性**的近义与关联词（动词发散动词、名词发散名词、形容词发散形容词）、同义词、反义词与实用例句，点击任意词即可发音；支持打卡与连续天数记录，也可翻看昨天/明天的词。词库为内链数据，离线也能打开。

另有独立的[拼写练习](spelling/index.html)：根据中文释义输入英文单词，每轮随机练习 20 词，支持提示、即时纠错、连续答对和本地统计。它与原单词卡页面相互独立，不改变原应用的界面和操作。

另有独立的[词义配对冲刺游戏](match-game/index.html)：在 60 秒内配对英文和中文释义，包含得分、连击、三颗生命、关卡时间奖励、暂停功能和本机最高分。可选择单个单元或全部词库。

另有全英文的[杜威十进制分类练习游戏 Dewey Quest](dewey-game/index.html)：直接练习杜威编码与英语主题的对应关系，可选择「编码 → 主题」「主题 → 编码」或混合模式。每轮 10 题覆盖全部十大类，选项随机排列，附即时答案解释、可展开的分类速查表、错题重练和各模式独立的本机最高分。无需加载外部词库，可离线打开。
