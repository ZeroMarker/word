# IELTS 单词卡片

一个无需构建步骤的 IELTS 单词学习网页。支持卡片翻面、单词/单元切换、系统英语发音、键盘操作，并自动保存上次学习位置。

## 本地运行

浏览器出于安全限制不能直接通过 `file://` 读取词库，请在项目目录启动一个静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 操作方式

- 点击卡片或按空格：翻面
- 左右滑动或方向键左右：切换单词
- 上下滑动或方向键上下：切换单元
- 点击音标、顶部扬声器或按 `P`：播放发音

词汇数据来自 `word-list.txt`。若词库加载失败，页面可切换到内置示例数据。
