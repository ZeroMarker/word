# IELTS 单词卡片

一个无需构建步骤的 IELTS 单词学习网页。支持卡片翻面、单词/单元切换、系统英语发音、键盘操作，并自动保存上次学习位置。

## 本地运行

浏览器出于安全限制不能直接通过 `file://` 读取词库，请在项目目录启动一个静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 操作方式

- 点击卡片或按空格：翻面
- 左右滑动或方向键左右：切换单词
- 上下滑动或方向键上下：切换单元
- 点击音标、顶部扬声器或按 `P`：播放发音

词汇数据来自 `word-list.txt`。若词库加载失败，页面可切换到内置示例数据。

## 其他学习方式

项目同时提供独立的[拼写练习](spelling/index.html)：根据中文释义输入英文单词，每轮随机练习 20 词，支持提示、即时纠错、连续答对和本地统计。它与原单词卡页面相互独立，不改变原应用的界面和操作。

另有独立的[词义配对冲刺游戏](match-game/index.html)：在 60 秒内配对英文和中文释义，包含得分、连击、三颗生命、关卡奖励和本机最高分。可选择单个单元或全部词库。
